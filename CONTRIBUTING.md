Thank you for your interest in contributing to PythonMETARExport!

Please follow these guidelines to make collaboration smooth.

- Fork the repository and create a topic branch for your changes.
- Keep changes focused and open small pull requests.
- Write tests for new features or bug fixes.
- Run tests locally with `pytest` before submitting a PR.
- Follow PEP8 coding style; use `black`/`ruff` if available.

Submitting a PR
- Describe the problem your change fixes and include relevant screenshots or logs.
- Reference any related issues using `#<issue-number>`.
- Ensure the test suite passes.

Code of Conduct
- Be respectful and constructive in feedback.

Maintainers may close or request changes to PRs that lack tests, are out-of-scope, or include unrelated formatting changes.
